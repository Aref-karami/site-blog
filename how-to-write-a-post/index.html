How to write a post on this site

A quick reference for adding posts, covers and tags.

By Aref Karami

Create a new file in content/blog, for example my-new-post.md. The file name becomes the URL: blog.arefkarami.ir/my-new-post/.

At the top of the file, add the front matter:

---
title: My new post
description: One sentence that shows in the list.
date: 2026-11-20
tags: [design, ai]
cover: ./images/my-cover.png   # optional
draft: false                   # true hides the post
---

Then write the rest in normal Markdown. Push to GitHub and the site rebuilds itself.
